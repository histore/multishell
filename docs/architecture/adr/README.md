# Architectural Decision Records (ADR)

This directory contains Architectural Decision Records (ADR) capturing significant architectural choices, rationale, alternatives considered, and trade-offs for the MultiShell project.

## Format
Each ADR follows the standard structure:
- **Status**: Proposed | Accepted | Superseded | Deprecated
- **Context**: Problem statement and forces influencing the decision
- **Decision**: Chosen solution and architectural mechanism
- **Consequences**: Positive and negative trade-offs, follow-up actions

## Index
*Architectural decisions and component responsibilities are maintained across modular specifications in [`docs/architecture/modules/`](../modules/). As dedicated ADR documents are authored, they will be indexed here.*
